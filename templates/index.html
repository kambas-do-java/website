Sobre Nós

Os Kambas do Java são uma comunidade vibrante de desenvolvedores baseada em Luanda, Angola. Nosso objetivo é promover a linguagem de programação Java e seu ecossistema, através do compartilhamento de conhecimento, networking e colaboração.

Organizamos meetups regulares, workshops e eventos para conectar desenvolvedores de todos os níveis, desde iniciantes até experts.
