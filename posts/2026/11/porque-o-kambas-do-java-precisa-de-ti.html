Porque o Kambas do Java precisa de ti

Dumilde Fernando · 9 de novembro de 2026 · 2 min de leitura

  • Comunidade
  • Contribuir
  • JUG Luanda

Vamos ser diretos: o Kambas do Java é pequeno. Depende de poucas pessoas e, se essas pessoas se cansarem, a comunidade pára. Não é uma frase dramática, é como qualquer comunidade de voluntários funciona.

Também achamos que merece existir. Luanda tem programadores Java bons, estudantes a aprender e empresas a contratar, mas poucos sítios onde se encontram, trocam dúvidas em português e aprendem uns com os outros. Esse sítio pode ser aqui.

O que não precisas de ser

Não precisas de ser especialista. Não precisas de dar palestras. Não precisas de tempo todas as semanas.

O que precisamos

  • Que apareças. Entra no Discord, lê, faz uma pergunta. Uma comunidade com gente a perguntar já é uma comunidade viva.
  • Que respondas. Sabes algo que alguém acabou de perguntar? Responde.
  • Que escrevas. Um artigo curto sobre algo que aprendeste esta semana vale mais do que um tutorial perfeito que nunca é publicado.
  • Que proponhas encontros. Um encontro pode ser seis pessoas, um café e um portátil.
  • Que tragas alguém. Um colega, um estudante, um amigo.

Como contribuir para este site

Tudo aqui é Markdown num repositório do GitHub. Para adicionar conteúdo, abre um pull request.

O teu perfil

Cria members/o-teu-utilizador-github.md:

@name O Teu Nome
@role Programador Java
@socials LinkedIn: https://linkedin.com/in/o-teu-perfil

Uma ou duas frases sobre ti e o que gostas de fazer com Java.

Um artigo

Cria posts/AAAA/MM/titulo-do-artigo.md:

@title O título do artigo
@description Uma frase que resume o artigo.
@tags Java, Tutorial

O texto em Markdown começa aqui.

Um evento

Cria events/nome-do-evento.md:

@title Nome do evento
@date 2026-12-05
@location Onde vai ser
@type meetup
@description Uma frase sobre o evento.

Os detalhes aqui.
